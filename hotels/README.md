# hotels/

Один файл — один готель. Файл описує **стан**, до якого готель має прийти, а
не список дій.

```bash
node scripts/apply-hotel.mjs hotels/schlossberghotel.json --dry-run   # показати, нічого не писати
node scripts/apply-hotel.mjs hotels/schlossberghotel.json             # прикласти
```

Деплой прикладає **всі** файли цієї теки після міграцій — і на беті, і на
проді. Тому завести другий готель це:

1. покласти сюди `<slug>.json`,
2. `git push`.

Ні SSH, ні доступів до адмінки, ні мережевих політик, ні ручного вводу.

## Що гарантується

* **Ідемпотентно.** Прикласти двічі — те саме, що прикласти раз.
* **Нічого не видаляється.** Прибрати рядок із файла — це не команда стерти
  номер, у якому хтось живе. Видаляють руками в адмінці.
* **Чужого не чіпає.** Усе всередині `runWithOrganization()` тієї організації,
  яку названо в `organization.slug`.
* **Нічого не вигадує.** Ціни, якої нема у файлі, не з'явиться.

## Ключі, за якими рядок упізнається

| Розділ | Ключ |
|---|---|
| організація | `slug` |
| ставка ПДВ | `code` + `validFrom` |
| серія фактур | `code` |
| категорія, будівля | `name` |
| тип номера | `code` |
| ціна заселеності | тип + `persons` + вікно `validFrom…validTo` |
| LOS | тип + `minNights` + `persons` |
| правило каналу | `channel` (порожній = за замовчуванням) |
| номер | `code` |
| послуга | `name` |

Збіг за ключем і різне число — це **зміна ціни**, і вона застосовується. Інший
ключ — це **новий рядок**. Тому змінити ціну означає виправити число на місці,
а не дописати рядок нижче.

## Приймальні перевірки

`acceptance` — не документація, а умова успіху. Файл сам каже, скільки має
коштувати кілька конкретних проживань, і прогін **падає**, якщо система рахує
інакше. Заведення без цього розділу означає «рядки лягли», а не «готель продає
правильно».

## Пароль власника

При першому створенні організації пароль генерується і друкується **один раз**
у лог деплою. Ніде не зберігається. Змініть при першому вході. У файл пароль не
кладіть — він поїде в git.

## Чому дані клієнта лежать у репозиторії

Правило AGENTS «жодної логіки під готель X» — про **код**. Ця тека і є те єдине
місце, де бізнес клієнта має право бути файлом: він читається на льоту і ніколи
не імпортується. `check-no-tenant-names.mjs` виносить `hotels/` саме з цієї
причини, і тільки її.

Шаблон з усіма розділами — `example.json`.
