# Мова інтерфейсу

**Звідки:** docs/BUILD-PLAN.md, розділ «Мова інтерфейсу» і Блок 1. **Ухвалив:**
власник, 03.09.2026 (DECISIONS П11). Це не гайд зі стилю — це те, з чого
складаються екрани, і те, чого на них не буває.

## 1. Патерни, які беремо

Спостережені в панелі Channex. Беремо структуру і поведінку; кольори, іконки,
тексти й точний макет — ні, це чужа робота і чужий бренд.

| Патерн | Де в коді | Стан |
|---|---|---|
| Верхня смуга: назва екрана ліворуч, **обʼєкт праворуч**, пошук, акаунт | `components/layout/Header.tsx`, `mobile/MobileHeader.tsx`, `layout/PropertySwitcher.tsx` | є. Назва обʼєкта видна завжди; перемикач — коли обʼєктів два й більше |
| Щільна таблиця: рядок заголовків, один рядок — одна сутність, дії праворуч | `.table` у `globals.css`; броні, номери, тарифи | є; колонка «Обʼєкт» у списках за «Усі обʼєкти» |
| Картка з двома діями (налаштувати / видалити) там, де сутностей мало | обʼєкти, зʼєднання каналів | є |
| Вкладки всередині сутності («Інформація», «Історія змін») | картка броні `BookingViewModal`, `MobileBookingDetail` | є |
| Порожній стан одним реченням — **і кнопкою** (див. §3) | `components/ui/State.tsx` | є; впроваджується екран за екраном |

Календаря в Channex немає — це адмінка менеджера каналів. Форма календаря
береться з дослідження Hoteliera (`harvest/`, `docs/research/hoteliera-product-map.md`)
у Блоці 3.

## 2. Токени

Один набір, `src/app/globals.css` → `:root`. Екран не вигадує власних кольорів
і відступів: якщо токена бракує, він додається сюди і дістає імʼя за змістом,
не за значенням (`--accent-danger`, не `--red`).

| Група | Токени | Для чого |
|---|---|---|
| Тло | `--bg-primary` `--bg-secondary` `--bg-tertiary` `--bg-card` `--bg-card-hover` `--bg-input` `--bg-sidebar` `--bg-header` `--bg-modal-overlay` `--bg-glass` `--bg-tooltip` | поверхні від найглибшої до найближчої |
| Межі | `--border-primary` `--border-secondary` `--border-hover` `--border-active` | лінії; `active` = фокус і вибір |
| Текст | `--text-primary` `--text-secondary` `--text-tertiary` `--text-inverse` `--text-link` | три рівні ваги; третій — підписи й підказки |
| Акценти | `--accent-primary(-hover, -light)` `--accent-success(-light)` `--accent-warning(-light)` `--accent-danger(-light)` `--accent-info(-light)` | дія, добре, увага, погано, довідково; `-light` — тло під текст того ж кольору |
| Статуси броні | `--status-draft` `--status-tentative` `--status-confirmed` `--status-checked-in` `--status-checked-out` `--status-cancelled` `--status-no-show` | один колір на статус на всіх екранах |
| Категорії | `--category-glamping` `--category-resort` `--category-camping` | колір категорії номерів |
| Тіні | `--shadow-sm` `--shadow-md` `--shadow-lg` `--shadow-glow` | підйом над поверхнею |
| Радіуси | `--radius-xs` … `--radius-xl` `--radius-full` | 4 → 16 px і коло |
| Шрифти | `--font-sans` `--font-mono` | текст і коди (id, коди броней, task id) |
| Розміри оболонки | `--sidebar-width` `--sidebar-collapsed-width` `--header-height` | |
| Рух | `--transition-fast` `--transition-base` `--transition-slow` | |
| Шари | `--z-sidebar` `--z-header` `--z-sticky` `--z-dropdown` `--z-modal` `--z-tooltip` | |

Типографіка: базовий розмір 14 px (`html`), таблиці й форми 13 px, підписи
12 px, коди — `--font-mono` 10.5–12 px. Тема одна (темна); світлої немає, і
токени названі за роллю саме для того, щоб вона зʼявилась зміною значень, а
не екранів.

## 3. Чотири стани екрана

`src/components/ui/State.tsx` — `EmptyState`, `LoadingState`, `ErrorState`,
`DeniedState`. Екран не малює їх сам.

- **Порожньо** каже, що саме порожнє, **що робити далі, і дає кнопку**. «Тарифів
  ще немає» + «Додати тариф». Без кнопки — лише коли дія неможлива (пошук
  нічого не дав: тоді підказка змінити фільтр). Це перше з трьох місць, де
  робимо краще за Channex («No items created yet»).
- **Завантаження** — один підпис на всі екрани.
- **Помилка** — зламалось у нас: підпис, пояснення екрана і «Спробувати ще
  раз». Текст помилки сервера сюди не потрапляє (інваріант 6).
- **Відмова** — доступу немає, і це не поломка: роль без права, чужий обʼєкт.
  Вимкнений модуль малює `ModuleGate` зі своїм текстом.

Окремий випадок — екран, якому потрібен рівно один обʼєкт, а обрано «Усі»:
`components/layout/PropertyRequired.tsx` показує вибір із кнопками.

Де вже стоїть (Блок 1): тарифи, ціни за заселеністю, номерний фонд, обʼєкти,
броні (десктоп і телефон), дашборд. Решта екранів переходить у Блоці 4 —
разом із приведенням до цієї мови.

## 4. Три речі, де робимо краще за Channex

1. **Історія показує різницю, а не повний знімок.** «Дати: 07–10 → 07–12»,
   «Тип: Twin → Double» — `modules/bookings/domain/booking-history.ts`,
   вкладка «Історія змін» на картці броні. Повний знімок лишається в
   `before_json`/`after_json` і не показується.
2. **Видно «хто».** Кожен запис історії називає автора: людину з сесії або
   канал із кодом броні («Booking.com · channex»).
3. **Порожні стани кажуть, що робити далі**, і дають кнопку (§3).

## 5. Чого не буває

- Власного стану області обʼєкта на екрані (`check-property-scope.mjs`).
- Кольору літералом там, де є токен статусу чи акценту.
- Порожнього списку без речення і без дії.
- Тексту з `e.message` сервера в інтерфейсі.
- Кнопки, яка виглядає робочою і не робить нічого: якщо функції ще немає —
  кнопка вимкнена і каже «скоро» (дзвіночок у шапці).
