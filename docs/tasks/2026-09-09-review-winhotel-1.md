його **текстові** виходи в гілку `claude/winhotel-schema` у теку
`docs/research/winhotel/extract-out/` (`header.txt`, `DDL.sql`, `table-counts*.tsv`,
`table-columns.tsv`, `keyword-hits.txt`, за потреби `samples.txt` для довідників),
видаляє базу і дає сесії 5 наступний номер. Далі сесія 5 виконує §2 задачі цілком
з цих виходів — без бази в її контейнері.

Шляхи 1 (політика мережі) і 2 (asset у GitHub) відхилено: перший не в наших руках

(`docs/tasks/inbox/session-4.md`, `session-5.md`), разом із рецензіями. Команда
очікування для цих двох сесій читає саме її:

```bash
MINE=<номер задачі, яку щойно зробив>
for i in $(seq 1 40); do
  git fetch -q origin claude/controller-2
  N=$(git show origin/claude/controller-2:docs/tasks/inbox/session-<N>.md \
      | head -1 | grep -oE '[0-9]+')
  if [ "${N:-0}" -gt "$MINE" ]; then echo "НОВА ЗАДАЧА: $N"; break; fi
  sleep 120
done
```

свою гілку щойно зелено; задача — блок) без змін.
