## Версія Firebird / ODS, чим відновлено, пароль

- Допоміжні бази: **Firebird 3.0, ODS 12.0**, діалект 3, сторінка 8192, charset `NONE`,
  створені тим самим Winhotel (шлях `C:\winhotelmx\daten\` у бекапі) — головна база
  майже напевно та сама версія, тобто `.FDB` відкриється `isql-fb` напряму.
- `WHMXDOKUMENT.fbk` відновлено `gbak -c` (embedded); DDL з відновленої копії і з
  `.FDB` збігаються байт у байт.
- **Пароль SYSDBA не знадобився і не перевіряється**: embedded-відновлення з навмисно
  неправильним паролем пройшло.
- `gstat` в Ubuntu-пакеті відсутній — заголовок читається `SHOW DATABASE`.

## П'ять найважливіших знахідок для імпортера (з того, що є)

1. **Зовнішніх ключів немає** — зв'язки лише за іменами колонок (`LNR_GK`, `LNR_ADR`,
   `RECHNR`); імпорт мусить рахувати сироти й звітувати, а не падати.
2. **`LNR` ставиться тригером лише при NULL** — історичні id можуть бути «ручними»,
   поза послідовністю генератора; не покладатись на монотонність.
3. **Charset NONE** — байти без кодування; для німецької Windows-програми це WIN1252,
   довести на умлаутах перед імпортом прізвищ (Meldeschein).
4. **Тип одного посилання різний між таблицями** (`BIGINT` проти `INTEGER` для
   `LNR_GK`) — мапу типів будувати по кожній таблиці, не по одній.
5. **Документи — `BLOB SUB_TYPE 0`** (бінарний): якщо головна база так само тримає
   листи/пропозиції, це RTF/Word-потік, а не текст — імпортувати як файл.
