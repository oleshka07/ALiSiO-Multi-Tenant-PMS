**1. Робоча смуга — дефект, знайдений живим запуском.** На 1080×1920 `.kiosk-band` стоїть
на 55–88 % висоти замість 35–85 % (§3.2), перша кнопка починається вище краю смуги і
обрізана; на екрані пошуку поля «Nachname» не видно, нижній ряд клавіатури з «Weiter»
під «Rezeption anrufen». Причини: `bandStyle` (`useKiosk.ts:104–110`) дає `marginTop`
елементу ПІСЛЯ шапки, тож відлік іде від низу шапки, а не від верху екрана; `.kiosk-band`
(`kiosk.css:34–41`) центрує `justify-content:center` при `overflow-y:auto`, і надлишок
обрізається з обох боків. Зроби смугу положенням від екрана (`position:absolute;
top:${top}vh; height:${bottom-top}vh`), центрування — `safe center` або `margin:auto`
внутрішнього блоку, і підбери розміри так, щоб **екран пошуку (два поля + клавіатура +
«Weiter») уміщався в 50 vh на 1080×1920 без прокрутки**. Доказ — не `tsc`: Playwright
уже в `node_modules`, Chromium — `/opt/pw-browsers/chromium` (`args: ['--no-sandbox']`);
у звіт — `boundingBox()` смуги і першої кнопки числами на стартовому екрані та екрані
пошуку, обидва 1080×1920, і два PNG у `docs/tasks/` (без даних гостей — там їх і немає).
Рядок у README оболонки: шрифт — Google Fonts, без мережі буде запасний.
