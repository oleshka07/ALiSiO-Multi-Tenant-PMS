саме на нечутливій до регістру ФС обхід диска показав би один файл і не
побачив би нічого.

   директорія цілком)**, а не списком навмання; `invoicing` і `dashboard` не
   входять — вони `ON`.
5. **Стелі `core→finance` = 1 і `pricing→channels` = 9 записані як застав.**

6. **Четверта Прага (`saveGeneralSettings`) виправлена**, хоч задача її не

такій базі ізоляція показала б зелене на будь-якому коді.

**Дві речі, яких середовище не дало відразу, і як вирішені:**

1. `check-isolation` падав на `APP_SECRET_KEY не налаштовано` — 503, не моя
   зміна. Ключ **64 hex** (`.env.example:53-55`), не base64; з правильним —
   зелено.
2. Playwright шукав `chrome-headless-shell` build **1234**, а образ має
   Chromium **1194**. Прогін зроблено тимчасовим конфігом із
   `executablePath: /opt/pw-browsers/chromium-1194/chrome-linux/chrome`;
   конфіг **видалено після прогону**, у гілці його немає. Різниця в збірці
   браузера, не в коді.

## Що потрібно від власника або контролера

**1. Рішення по `DEFAULT 'Europe/Prague'` на колонці.** Зняти його — це 56
файлів у чужих теках. Список відтворюється:

```bash
grep -rln "INSERT INTO organizations" src/ scripts/ | while read f; do
  grep -q "INSERT INTO organizations[^;]*timezone" "$f" || echo "$f"
done
```

**2. Демо-орендар із засіву заводиться без роду житла.**
`src/lib/db.ts:7514-7518` вставляє організацію без поясу (бере `DEFAULT`
колонки) і обʼєкт без `property_type`. Тобто на кожній машині розробника і в
`check-fresh-schema` стоїть готель, який **не може синкнути каталог**. Прага
там правдива (обʼєкт у Празі, `CZ`), а рід житла — ні. Не чіпав: `src/lib/db.ts`
поза теками задачі, і зміна в ньому тягне `build:win` +
`check-fresh-schema` за AGENTS §4. Правка — одне слово в тому `INSERT`:

```bash
sed -n '7514,7519p' src/lib/db.ts
```

**3. Роди житла у файлах готелів проставлені мною як `hotel`** — для
`schlossberghotel` і `demo-hotel` це схоже на правду, але значення «affects
billing» у вендора, тобто вирішує, скільки готель ЗАПЛАТИТЬ. Звірити з
готелем:

```bash
grep -n propertyType hotels/*.json
```
