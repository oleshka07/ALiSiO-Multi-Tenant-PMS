# Winhotel.MX — зразки довідників

Порожньо станом на 09.09.2026: єдина отримана база (`WHMXDOKUMENT.FDB`) не містить
довідників і не містить рядків узагалі. Головна база не отримана — `notes.md` §1.

## Правила для того, хто заповнить

- Лише довідники **без персональних даних**: категорії номерів, номери, послуги
  (`Leistungen`), ставки ПДВ, цінові таблиці й сезони, політики Storno, джерела броні
  (`Buchungs-Segm.`), способи оплати. По 5–10 рядків на таблицю.
- **Жодного рядка** з гостей, адрес, компаній/дебіторів, броней, фактур, оплат,
  ваучерів з іменем — навіть знеособленого. Імена, адреси, IBAN, номери карток,
  e-mail не потрапляють у git ні в якому вигляді (AGENTS.md §3 інваріант 7).
- Зразки бере `extract.sh --sample T1,T2` — **лише** для таблиць, названих явно,
  після того, як їх колонки прочитано в `table-columns.tsv` і в них немає полів
  на кшталт `NAME`, вулиці, `PLZ`, `ORT`, `TEL`, `MAIL`, банківського рахунку, `KONTO`, `KARTE`.
- Перед комітом: `git grep -iE "iban|@|strasse|str\." docs/research/winhotel/` порожній.
