Задача: `docs/tasks/2026-09-09-winhotel-schema.md`. Звіт:
`docs/tasks/2026-09-09-winhotel-schema.report.md`. Це дослідження, не код: нічого
звідси не імпортується продуктом. Знімок бази — **11.03.2025** (`notes.md` §3).

Перед наступним витягом (свіжий `.fbk` перед вимкненням Winhotel): запустити
`extract.sh` з `--sample` для `DEVISEN,SEGMSTAM,ADR_AUSWAHL,STEUSTAM,KATESTAM,ZIMMSTAM`
(довідники без персональних даних; **не** `PARAMETE_WEB`, `FREIMELD_PRO`, `BEDIENER`,
`MANDANT` — там паролі) і забрати `aggregates.txt` у `COUNTS-*.md`.

Перед комітом сюди: PII-grep з §4 задачі (шаблон там) поза `extract-out/` і `extract.sh`
має бути порожнім; рядки гостей, компаній, броней, фактур, оплат не потрапляють у git
ні в якому вигляді.
